PART 1: AUDIO CAPTCHA SYSTEM (Task 2.1)
================================================================================

The Audio CAPTCHA generates random alphanumeric strings (5-7 characters) 
verified through speech synthesis rather than visual recognition, improving 
accessibility. Each CAPTCHA randomly applies one of six audio effects 
(lowpass, highpass, bandpass, reverb, delay, or none) to create variable 
difficulty levels.

Implementation uses Web Speech API's SpeechSynthesisUtterance for character-
by-character narration with controlled rate (0.8), pitch, and volume. 
Synchronized p5.Oscillator tones generate frequency-mapped audio (numbers: 
300-750Hz, letters: 400-1025Hz) that feeds into p5.FFT for real-time 
visualization. The symmetric frequency bar display provides visual feedback 
during playback, with the current effect clearly labeled.

The interface features play/pause control, refresh button, text input, and 
real-time status messages. Testing confirmed successful generation, clear 
synthesis, and accurate validation across all effect types.

================================================================================
PART 2: AUDIO FEATURES AND VISUAL MAPPING (Task 2.2)
================================================================================

Three audio files transform into distinct visualizations using Meyda feature 
extraction, with feature combinations selected to maximize visual impact:

**Sound 1: Spectral Flatness + Spectral Kurtosis + Energy**
Spectral flatness drives polygon morphing (smooth circles for tonal content, 
jagged shapes for noise), providing immediate timbral feedback. Spectral 
kurtosis controls bar heights representing frequency concentration, while 
energy generates pulsing circles scaled to signal power.

**Sound 2: Spectral Kurtosis + Energy + Zero Crossing Rate**
Kurtosis manifests as radial spikes communicating spectral peakedness. Energy 
provides amplitude context through central pulsing circles. Zero crossing 
rate animates waveform jaggedness, with high ZCR producing rough waves for 
percussive content and smooth waves for tonal sounds.

**Sound 3: Energy + Spectral Skewness + RMS**
Energy drives the primary visualization selected for strongest dynamic range. 
Spectral skewness creates asymmetric wave patterns indicating frequency 
distribution bias. RMS complements energy with averaged amplitude envelopes.

Each mapping employs intuitive metaphors (size for loudness, shape for 
timbre) and complementary dimensions combining time, frequency, and amplitude 
features to ensure visible, meaningful variations.

================================================================================
PART 3: VOICE CONTROLLER IMPLEMENTATION (Task 2.3)
================================================================================

The voice controller uses p5.SpeechRec for hands-free visualization control 
through ten commands: five colors (Black, White, Red, Blue, Green) and four 
shapes (Square, Triangle, Circle, Pentagon). Continuous recognition mode with 
interim results enables natural speech patterns while preventing false 
triggers through final-result-only execution.

A pulsing microphone indicator provides real-time audio level feedback, 
confirming active listening status. Command processing uses lowercase 
normalization and substring matching to handle natural speech variations. 
The multi-layered visualization analyzes bass (20-140Hz), mid (140-400Hz), 
and treble (400-6000Hz) ranges via p5.FFT, with each driving separate shape 
layers for dynamic three-dimensional effects.

Testing achieved 500-1000ms recognition latency with successful command 
recognition in quiet environments. Background music interference and 
similar-sounding words presented challenges addressed through confirmation 
feedback and interim result displays.
